Excited to unveil my latest Cloud Computing & Full-Stack Capstone Project: **SkillSphere 3D — Online Hobby & Skills Tracker with Community Sharing on Cloud**! 🌐✨

Most people abandon hobbies and skill development due to a lack of structure and social accountability. To solve this, I designed and deployed a cloud-native platform that transforms daily practice into compounding streaks, backed by decentralized cloud object storage and real-time social engagement.

🌟 **Key Technical Highlights:**
🌌 **Immersive 3D Experience**: Integrated Three.js WebGL to render an interactive 3D Skill Galaxy Canvas with dynamic, category-tailored 3D tilt cards (Cyberpunk Matrix for Coding, Soundwave Equalizers for Guitar, Aperture Iris for Photography, Cardio ECG for Fitness).
☁️ **Decoupled Cloud Architecture**: Structured entity records are managed in Cloud Firestore NoSQL, while high-resolution certificates and practice proof media (< 5MB) are streamed to Google Cloud Object Storage, reducing database operational overhead.
⚡ **Serverless Event-Driven Streaks**: Cloud Functions calculate consecutive calendar streaks and aggregate weekly minutes asynchronously on `onCreate` document triggers.
🔒 **Cloud Security & Idempotency**: Declarative RBAC security rules enforce user-level data isolation, and composite primary keys (`postId_uid`) prevent duplicate likes.
