# Resume, LinkedIn & GitHub Pitch Kit: SkillSphere 3D

---

### A. Resume Bullet Points (Placement Ready)

- **Engineered a Cloud-Native Skill & Habit Tracking Platform (SkillSphere 3D)** utilizing React 18, Three.js WebGL, Google Cloud Firebase, and serverless background event functions, supporting real-time cross-device state synchronization.
- **Architected a Decoupled Cloud Storage Pipeline** that routes multi-part binary media uploads (< 5MB) to Google Cloud Storage while maintaining URI references in Firestore, reducing database document bloat and query latency.
- **Implemented an Event-Driven Streak Engine & Security Model** with Cloud Functions triggers calculating daily practice streaks, and authoring granular RBAC security rules to enforce data isolation and idempotent social like prevention.

### C. Professional LinkedIn Project Post

```markdown
🚀 Excited to share my latest Cloud Computing Capstone Project: **SkillSphere 3D — Online Hobby & Skills Tracker on Cloud**!

Consistent skill progression often breaks down due to lack of accountability and fragmented data across devices. To solve this, I designed and deployed a cloud-native platform where learners can track practice sessions, build compounding streaks, and share verified achievements with peers.

🌟 Key Technical Achievements:
- 🌌 **Immersive 3D Experience**: Integrated Three.js WebGL to render an interactive Skill Galaxy and dynamic, category-specific 3D perspective tilt cards for coding, music, photography, and fitness.
- ☁️ **Decoupled Cloud Architecture**: Separated structured documents (Firestore NoSQL) from binary media blobs (Google Cloud Storage), optimizing bandwidth and query speeds.
- ⚡ **Serverless Event-Driven Streaks**: Deployed Cloud Functions executing on `onCreate` triggers to compute consecutive calendar streaks and award milestone badges asynchronously.
- 🔒 **Enterprise Cloud Security**: Enforced role-based access control (RBAC) via declarative security rules and prevented duplicate likes via composite key indexing.

Check out the live deployment and source code on GitHub! Feedback is always welcome. 💡
```
